👑 VIP BOM 사진 계산

BOM 사진 첨부 → 생산수량 입력 → 자재위치·소요량 자동확인

1️⃣ 저장된 BOM PO 먼저 검색

기존에 등록한 PO는 사진을 다시 찍을 필요가 없습니다. PO번호와 이번 생산수량만 입력하면 저장 데이터로 자재위치·소요량·ERP 재고 차이를 바로 계산합니다.

2️⃣ 신규 PO만 BOM 사진 첨부

BOM 용지를 정면에서 선명하게 촬영해 주세요.

3️⃣ 신규 PO 사진 분석·저장

검색되지 않는 신규 PO일 때만 위에 PO번호·생산수량을 입력하고 사진을 분석하세요.
BOM 사진을 첨부하고 생산수량을 입력해 주세요.

📋 사진 분석 결과 · 자재위치·소요량

사진을 분석하면 자재 품번·창고위치·소요량이 표시됩니다.

📑 해당 PO 자재 최근 입고·출고·반환 내역

PO를 검색하면 포함 자재의 최근 이동 내역이 표시됩니다.

🗂️ 검토완료 BOM PO 목록

저장된 PO가 없습니다.
검토 완료한 BOM PO를 저장하면 여기에 누적됩니다.

🧹 기존 위치 정리·수정

ERP 전체 품목을 불러와 위치·구분·사용빈도·최소수량을 한 줄에서 등록·수정합니다. 위치가 없는 ERP 품목도 표시되며, 저장 후 관리자 메인 검색에 바로 연동됩니다.
위치 불러오기를 눌러주세요.

📊 기록 정리 · 엑셀 출력

입고·출고·반환 기록과 현재 입력한 품목을 구분별로 골라 출력합니다.
